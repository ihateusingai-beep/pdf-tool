## 2. PDF→TXT sub-feature

### 2.1 功能描述

User 上傳 1 個 PDF, click execute, 下載 1 個 `.txt` 檔案,內含 PDF 全部 page 嘅純文字(保持 page break separator)。

### 2.2 Implementation spec

**Helper signature:**
```js
async function extractTextFromPdf(arrayBuffer, options = {})
// options: { pageRange: string|null,  // "1,3,5-7" or null = all
//            includePageBreaks: boolean }  // default true
// Returns: { text: string, pageCount: number, charCount: number }
```

**Algorithm:**
1. `pdfjsLib.getDocument({ data: arrayBuffer.slice(0) })` 攞 doc
2. 攞 `doc.numPages` 計 total
3. Apply `pageRange` (用 v3.0.5 嘅 `parsePageSelection` helper, 1-based)
4. Loop 過 selected page:`const page = await doc.getPage(i)` → `const text = await page.getTextContent()`
5. Concatenate `items.map(it => it.str).join(' ')` 落 result
6. Page break: `result += '\n\n--- Page X ---\n\n'`
7. Return `{ text, pageCount, charCount }`

**LoC:** ~50

**UI 段** (喺新 mode-extract panel 入面):
```html
<fieldset class="border border-teal-200 rounded-lg p-3">
    <legend class="text-sm font-bold text-teal-700 px-2">📝 純文字提取 (TXT)</legend>
    <label class="block text-xs text-gray-600 mb-1">頁碼範圍（可選,留空=全部）</label>
    <input type="text" id="extract-txt-range" placeholder="例：1,3,5-7 或留空"
           class="w-full px-3 py-2 border border-gray-300 rounded-lg text-sm font-mono">
    <label class="flex items-center gap-2 text-xs text-gray-700 mt-2">
        <input type="checkbox" id="extract-txt-pagebreaks" checked class="w-4 h-4 rounded">
        <span>包含頁碼分隔 (--- Page N ---)</span>
    </label>
</fieldset>
```

### 2.3 TinyWow 對標

✅ 對標 TinyWow `PDF to Text` (我哋 tinywow-comparison.md §4.2 line 43)

### 2.4 Edge cases (F4 audit)

- Encrypted PDF: load 會 throw → 提示去 mode-more 解密先
- 0 頁 PDF: 提示「PDF 沒有頁面」
- Scanned PDF (冇 text layer): 提示「PDF 冇文字層,可能係掃描檔,建議啟用 OCR」+ 提示去 search mode
- 100MB+ file: hard reject (避免 OOM)

## 3. PDF→JPG/PNG sub-feature

### 3.1 功能描述

User 上傳 1 個 PDF, 揀 page range (可選) + JPG 質素, click execute, 全部 page 落 1 個 ZIP (multi-page) 或 1 個 image file (single-page)。

### 3.2 Implementation spec

**Helper signature:**
```js
async function renderPageToImage(pdf, pageNum, options = {})
// options: { scale: number,  // default 2.0
//            quality: number,  // 0.5 / 0.75 / 0.95
//            format: 'jpeg' | 'png' }
// Returns: Promise<Blob>

async function extractImagesFromPdf(arrayBuffer, options = {})
// options: { pageRange: string|null,
//            scale: number,
//            quality: number,
//            format: 'jpeg' | 'png' }
// Returns: Promise<{ blobs: Blob[], fileNames: string[] }>
```

**Algorithm:**
1. 載 PDF, parse pageRange
2. For each page:
   - `const page = await pdf.getPage(i)`
   - `const viewport = page.getViewport({ scale: 2.0 })`
   - Create canvas, render page
   - `canvas.toBlob(blob => ..., 'image/jpeg', 0.95)`
3. ZIP blobs (multi-page) OR direct download (single-page)
4. Memory: ZIP download 之後 `state.extractFile = null` (release)

**LoC:** ~80

**UI 段**:

### 5.7 `extract-execute` click handler (大約 60-80 LoC)

```js
document.getElementById('extract-execute').addEventListener('click', async () => {
    if (!state.extractFile) {
        toast('⚠️ 請先上傳 PDF', 'warn', 2500);
        return;
    }
    showLoading('正在提取 PDF 內容...');
    try {
        const arrayBuffer = await state.extractFile.arrayBuffer();
        const baseFilename = document.getElementById('extract-filename').value.trim() || 'extracted';

        // Check if TXT extraction has range option
        const txtRange = document.getElementById('extract-txt-range').value.trim();
        const includePageBreaks = document.getElementById('extract-txt-pagebreaks').checked;

        // TXT extraction
        const txtResult = await extractTextFromPdf(arrayBuffer, {
            pageRange: txtRange || null,
            includePageBreaks
        });
        const txtBlob = new Blob(['\uFEFF' + txtResult.text], { type: 'text/plain;charset=utf-8' });

        // JPG/PNG extraction
        const imgRange = document.getElementById('extract-img-range').value.trim();
        const format = document.getElementById('extract-img-format').value;
        const quality = parseFloat(document.getElementById('extract-img-quality').value);

        const imgResult = await extractImagesFromPdf(arrayBuffer, {
            pageRange: imgRange || null,
            scale: 2.0,
            quality,
            format
        });

        if (imgResult.blobs.length === 1) {
            // Single page: direct download
            downloadBlob(imgResult.blobs[0], `${baseFilename}_page1.${format}`);
        } else {
            // Multi-page: ZIP
            const zip = new JSZip();
            imgResult.blobs.forEach((blob, i) => {
                zip.file(imgResult.fileNames[i], blob);
            });
            zip.file(`${baseFilename}.txt`, txtBlob);
            const zipBlob = await zip.generateAsync({ type: 'blob' });
            downloadBlob(zipBlob, `${baseFilename}.zip`, 'application/zip');
        }

        // Memory release
        state.extractFile = null;
        document.getElementById('extract-input').value = '';
        document.getElementById('extract-filename-display').textContent = '';
        document.getElementById('extract-execute').disabled = true;
        updateMoreFilename();  // reuse helper pattern

        toast(`✅ 已提取: ${txtResult.pageCount} 頁 / ${txtResult.charCount} 字 / ${imgResult.blobs.length} 圖`, 'success', 4000);
    } catch (err) {
        toast(friendlyError(err, '提取失敗'), 'error', 5000);
    }
    hideLoading();
});
```
